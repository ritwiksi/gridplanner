# GridSeeker

**Find the right land for clean energy.**

Early-stage parcel screening for a proposed ground-mounted solar project near Albany, New York.

## Verification gate

This repository begins with a mandatory **GO/NO-GO** feasibility stage. Real New York State parcel polygons, projected-area calculations, and an independent geospatial constraint must be verified before a frontend is implemented. No generated parcels or invented suitability scores.

Development takes place on feature branches; `main` is preserved until a working change is reviewed.

Data: [NYS Public Tax Parcels, actual parcel layer 1](https://services6.arcgis.com/EbVsqZ18sv1kVJ3k/ArcGIS/rest/services/NYS_Tax_Parcels_Public/FeatureServer/1), [NYS freshwater wetlands](https://services2.arcgis.com/dU6jdOIkCUj2UDe9/ArcGIS/rest/services/Env_Wetlands_nysdec/FeatureServer/0).
